# Software requests
Department: IT
Updated: 2026-02-02

## The software catalogue

The IT service desk portal has a software catalogue of approved tools. Anything in the catalogue installs on your laptop at once, with no approval needed. The catalogue includes office tools, browsers, code editors, design tools and common developer tools. Check the catalogue first before you ask for something new.

## Asking for new software

To use software that is not in the catalogue, raise a software request in the IT service desk portal. Say what the software is for, who else might use it, and whether it will touch customer data. The Security team reviews each new request within 5 working days. Free software, trial versions and browser extensions also need a request, because free tools can still collect data. Software that handles Confidential or Restricted data needs a full security review, which takes up to 15 working days.

## Paid software

Paid software also needs your manager's approval for the cost. IT buys the licence; do not buy software with a personal card or the corporate card and claim it. Licences are reviewed every 6 months, and unused licences are removed.

## Open-source libraries in our products

Engineers may use open-source libraries in Fernhill products without a request, if the library's licence is on the approved list: MIT, Apache 2.0 and the BSD licences. Libraries under other licences need approval from the Head of Engineering. Record new libraries in the product's dependency file, so the automatic licence scan can check them.

## Cloud services and AI tools

Signing up for a cloud service with your work email counts as using new software and needs a request. AI tools have their own rules in the AI tools policy.

## Admin rights

Employees do not have administrator rights on their laptops. Developers who need temporary admin rights can request them in the portal for up to 8 hours at a time. Every use is logged.

## Removing software

Software that is not approved may be removed from your laptop without notice. If something you rely on is removed, raise a request and explain why you need it.

## Getting help

Call the IT service desk on extension 4400, or email it-help@fernhill.example.
