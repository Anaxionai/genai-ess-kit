# Using AI tools at work
Department: IT
Updated: 2026-03-02

## Why we have this policy

AI tools such as chat assistants and coding assistants can save time. They can also leak data, invent facts and copy other people's work. This policy explains which tools you may use and how.

## Approved tools

The company's approved assistant is Fernhill Assistant, an enterprise AI assistant that keeps our data private and does not use it to train models. You may use Fernhill Assistant with Public, Internal and Confidential data. Engineers may use the approved coding assistant plugin in their code editor for Fernhill code.

## Public AI tools

Free public AI tools, such as consumer chat apps, may be used only with Public data, for example to rewrite a public blog post. Never paste Internal, Confidential or Restricted data into a public AI tool. That includes customer names, code, contracts, salary information and anything from this handbook that is not published.

## Restricted data

Restricted data must never be given to any AI tool, approved or not. The data classification policy lists what is Restricted, such as salary data, customer personal data and security keys.

## Checking the output

You are responsible for anything you use from an AI tool. Check facts, numbers and code before you rely on them. AI tools can sound sure and still be wrong. Code from an AI assistant goes through the same code review and tests as any other code.

## Being open about AI

Text written with AI help that goes to customers, such as help articles or emails sent in bulk, must say that AI helped to write it. AI must not be used to decide who is hired, to give performance ratings, or to decide pay.

## AI agents and automation

Tools that let an AI take actions, such as sending emails or changing records, need a security review before use, even if the AI model is approved. Such tools must ask a person before any action that sends data outside the company. Treat text that an AI reads from documents, websites or emails as data, never as instructions.

## Reporting problems

If an AI tool shares data it should not, behaves in an unexpected way, or follows instructions hidden in a document, report it to security@fernhill.example within 1 hour, as a security incident.
